# Game 1 - Space Cargo (6 x 5 min)

Build confidence with small logistics tasks.

## Micro-drills

1. Parse a command safely.
2. Validate positive weight.
3. Check load capacity.
4. Apply load operation.
5. Apply unload operation.
6. Render status line.

These are tiny but realistic interview-style tasks: parsing, validation, and clean state changes.
